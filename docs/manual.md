# 使用手册（工程管理本地版）

> 面向使用者。装好之后的日常操作全在这里；部署与开发见根目录 `README.md`。

## 1. 启动与安装

**开发/本机运行**

```bash
npm install
npm run dev        # 打开 http://127.0.0.1:3100
```

**打包给同事用**

```bash
npm run build      # 产物在 dist/
```

`dist/` 必须通过一个 HTTP 服务打开（直接双击 `index.html` 不行，浏览器会拦截 IndexedDB 与模块加载）。最简单的办法：把 `dist/` 交给内网静态服务器，或者在本机 `dist` 目录下执行 `npx serve` / `npx http-server`。

## 2. 第一次打开要做的三件事

1. **选数据目录**（推荐）：系统设置 → 数据目录 → 「选择本地文件夹」，例如 `D:\工程数据`。
   - 选目录后，附件以真实文件形式存在这个目录里，可以用资源管理器直接看、直接备份到移动硬盘。
   - 不选也能用，附件会存在浏览器内部（OPFS/IndexedDB），只是看不见、不好单独拷。
2. **确认编号前缀**：系统设置 → 编号规则。默认前缀（如 `HT` 合同、`QZ` 签证）可改，**只影响新单**，老单编号不变。
3. **确认打印抬头**：系统设置 → 打印抬头，改成你们项目部/公司名称，打印和 PDF 都会用它。

> 浏览器重启后如果提示「数据目录尚未授权」，点页面顶部的「重新授权」即可。**这不是数据丢失**，只是浏览器要求重新确认一次目录权限。

## 3. 界面约定

- **左侧 12 个菜单**：首页看板、项目与 WBS、进度管理、合同·签证·结算、成本管理、质量安全、物资设备、文档图纸、劳务管理、预警汇总、回收站、台账导出中心。
- **顶部**：当前项目切换（多数单据按项目过滤）、全局搜索框（回车搜索）、预警铃铛（未读数）、设置下拉。
- **每个单据页**：上面是筛选栏（关键词/状态/日期区间），中间是表格，右下角是分页（共 N 条）。
- **单据行操作**：查看、编辑、打印、删除。**被锁定的单据「编辑/删除」是灰的**——这是正常的业务保护，不是故障，需要先「撤销锁定」（打开单据弹窗底部按钮）。

## 4. 建项目与 WBS

1. 项目与 WBS → 项目 tab → 「新增项目」：填项目编号、名称、状态（在建/已完工/已归档）。
2. 切到 WBS tab：可以「新增 WBS」逐条建，也可以「导入」：
   - **MS Project XML**：从 Project 导出 XML 后直接导入，层级、名称、日期都会被识别；
   - **Excel**：下载模板后按列填（编码、名称、计划开始、计划结束、工期、完成率）。
3. WBS 支持层级（父/子）、停用（停用父节点会连带停用子节点）。
4. 下方是**甘特图**：蓝色计划条 + 绿色实际条，可缩放，可导出 PNG。

**注意**：WBS 有子节点、或被任何单据（含回收站里的）引用时，**不允许删除**。系统会告诉你被什么挡住。如果这个 WBS 只是不再使用，请改成「停用」。

## 5. 录一张单据（以现场签证为例）

合同·签证·结算 → 签证 tab → 「新增现场签证」：

1. 编号自动生成（`QZ-20261106-0001`），可点「重新取号」重取，也可手改（保存时查重）。
2. 选合同、选 WBS（必填，红色 `*`）。
3. 填签证事由、工作内容、工程量、综合单价 → **合价自动算**，只读。
4. 监理确认状态默认「待确认」。改成「已确认」后，该单据被锁定，不能再编辑/删除。
5. 附件区可一次选多个文件，任意大小；图片和 PDF 可在线预览，其他格式可下载。
6. 保存。要留档就点「打印」→ 浏览器打印对话框里选「另存为 PDF」。

**通用规则**：必填项留空保存会一次性列出所有错误并把字段标红；弹窗「关闭」会丢弃本次填写与本次临时上传的附件。

## 6. 首页看板

- 8 张指标卡：在建项目数、未闭环隐患、应收未收、本月产值、库存告警、超预算项目、证件到期、待整改缺陷。
- **点卡片可下钻**到对应列表，且筛选条件已自动带好。
- 卡片可配置：右上角「配置」里可勾选显示哪些卡、拖动排序，「恢复默认」可复位。
- **今日计划**：把「今日到期整改单 / 逾期未闭环隐患 / 今日到期证件 / 该填报但未填报的进度」聚合在一起，可勾选完成；也可以自己加待办。
- 两张图：成本与产值趋势、进度偏差（挣值 SPI/CPI）。

## 7. 常见业务链

| 想做的事 | 路径 |
|---|---|
| 变更没批准就想签证 | 不允许。先把变更洽商的审批状态改成「已批」，再建签证 |
| 材料进场要送检 | 物资设备 → 材料进场送检：是否送检=是、结论=合格才入库；不合格不入库并产生预警 |
| 检验批不合格 | 质量安全 → 检验批记录 → 行内「建缺陷单」，自动带出检验批编号，缺陷状态=待整改 |
| 隐患整改完 | 打开隐患单，复查结论改「合格闭环」→ 单据锁定、对应预警自动转已读 |
| 给班组发工资 | 劳务管理 → 班组计量（审核通过）→ 工资发放 → 「按已审核计量取数」 |
| 设备退场 | 设备台账状态改「退场」后，不能再给它记台班；班组退场同理，不能再加人/录考勤 |

## 8. 搜索

顶部搜索框输入关键词回车（或左侧菜单外的「全局搜索」页）：

- **空格分隔多个词 = 同时满足**（AND）。搜「3号楼 防水」只出同时含这两个词的记录。
- 能搜到：单据编号、名称、描述文本、项目名、WBS 编码/名称、附件文件名、单据类型名（搜「隐患」能出隐患单）。
- 命中词黄色高亮，条目带类型标签与上下文摘要。
- 结果页可再按项目/类型/时间筛选，可导出 Excel（导出的是当前筛选结果）。
- 结果超过 200 条会提示缩小范围；页面上显示「当前 N 条」。

## 9. 导出与打印

- **单张单据**：行内「打印」→ 新窗口 A4 版式 → 浏览器打印 / 另存 PDF。抬头取系统设置里的配置。
- **整本台账**：台账导出中心 → 选项目、单据类型、日期区间、勾选需要的字段 → 生成 Excel。金额列千分位、表头冻结、带自动筛选。
- **甘特图**：项目页甘特图右上角可导出 PNG。

## 10. 备份与恢复（最重要的一节）

**数据只存在这台电脑的这个浏览器里。换电脑、重装系统、清浏览器缓存前必须先导出备份。**

- 导出：系统设置 → 备份 → 「导出整包备份」→ 得到 `工程管理备份_YYYY-MM-DD.zip`。
  包内含 `manifest.json`、`data/`（每张表一个 JSON）、`files/`（附件字节）。
- 导入：系统设置 → 备份 → 选择 zip → 选冲突策略：
  - **跳过**：已存在的同编号不动（最安全）；
  - **覆盖**：用包里的内容覆盖本地同编号；
  - **另存为新编号**：编号加 `-R1`，两边都保留，父子引用会自动迁到新编号。
- **清空后整体恢复**：先清空本地数据再导入，适合「换机迁移」。会弹红色二次确认。
- 建议节奏：每周一次整包备份，重要节点（结算、验收）当天再备一次。

## 11. 回收站

- 删除单据是**软删除**：从列表消失，进回收站，**保留 90 天**，到期在启动时自动清理。
- 回收站里可「恢复」（回到原模块，附件还在）或「永久删除」（记录与附件字节一起删，不可恢复）。
- 恢复时如果编号已被新单据占用，系统会自动改成 `-R1`，不会失败。
- 剩余 ≤7 天的记录会在回收站页顶部提醒。

## 12. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 附件传不上去，提示目录授权失效 | 浏览器重启后权限失效。点顶部「重新授权」或在设置页重选目录，已上传的文件不会丢 |
| 提示存储容量不足 | 清理回收站（永久删除）或换一个空间更大的数据目录 |
| 「编辑/删除」是灰的 | 单据被锁定（如隐患已闭环、签证已确认、结算已收款）。打开单据点「撤销锁定」，或先改状态 |
| 列表里看不到刚录的单据 | 检查顶部当前项目是否切对了；检查筛选栏的关键词/状态/日期是否残留 |
| 打印出来没有表头文字 | 设置页「打印抬头」没填 |
| 换浏览器后数据不见了 | IndexedDB 按浏览器隔离。用备份包迁移，别直接换浏览器 |
| 想彻底重来 | 系统设置 → 危险操作 → 清空全部数据（红色二次确认，含附件）。**先导出备份** |
