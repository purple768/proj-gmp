## 2. 关键口径明细

### R-02 结算

| 项 | 实现 |
|---|---|
| 结算总金额 | 手工录入必填，不由报审自动汇总 |
| 参考值 | `referenceValues()`：Σ已审核报审 + Σ已确认签证（同合同过滤），合同额单列 |
| 差异提示 | 与参考值差异 > 5% → warning，不阻断 |
| 已收金额 | `0 ≤ 已收 ≤ 结算总金额`，超出直接 error 拦截 |
| 未收余额 | `max(0, 结算 − 已收)`，computed |
| 首页应收 | 只统计 `待收款 / 部分收款`，已结清与软删不计 |
| 一合同多结算 | 累计结算 > （合同额 + 已批变更净额 + 已确认签证）× 110% → warning，不阻断 |

### R-04 甘特图与挣值

- **叶子节点实际条**：起点 = 计划开始，长度 = `完成率 × 计划工期`；完成率为 0 不画条（与「无填报」区分）。
- **父节点**：只有展示层按子项**工期加权**聚合；**挣值与预警只认自身填报**，不会因为子项填了就替父项判定。
- **工期预警**：预计工期 = 计划工期 ÷ 完成率，偏差 > 7 天为紧急；完成率 100% 不产生预警。

### R-05 删除与停用

三级拦截，**不级联删除**：

1. 有子节点 → 拒绝，并给出子节点条数；
2. 被单据引用（含回收站里的）→ 拒绝，并按单据类型给出条数；
3. 项目下还有 WBS 或任何单据 → 拒绝，提示改为「已完工 / 归档」。

停用父节点会递归停用子节点；**启用父节点不会自动放开子节点**（避免误操作把整棵树打开）。

### R-06 配额与失败提示

| 场景 | 行为 |
|---|---|
| 已用 ≥ 80% | 黄条提醒，不阻断上传 |
| 已用 ≥ 95% 且单文件 > 10MB（非目录模式） | 拦截，提示清理回收站或换目录 |
| 写入抛 `QuotaExceededError` | 「存储容量不足，请清理回收站或更换数据目录后重试」 |
| 写入抛 `NotAllowedError` | **自动尝试重新授权一次**，仍失败则提示「数据目录授权已失效」 |
| 写入抛 `NotReadableError / InvalidStateError` | 「文件正被其他程序占用，请关闭该文件后重试」 |

设置页显示占用进度条：<80% 绿、≥80% 黄、≥95% 红。

### R-07 回收站与物理文件

```
软删除单据 → attachments.state = pending-trash（字节保留，可预览）
恢复       → state = active
永久删除 / 到期清理 → refCount-- ，归零才删字节
```

保留 90 天，启动时清理；剩余 ≤7 天在回收站页顶部提醒；恢复时编号被占用自动改 `-R1`。

### R-12 库存

- 归一键：`项目 + 名称 + 规格`（不同项目不合并）。
- 入库时机：送检=否，或送检=是且结论=合格 → 生成入库流水；不合格/待出报告→不入库。
- `applyReceipt()` 幂等：同一进场单重复保存不会重复入库。
- 出库不得超库存；进场会回写需求计划状态：待采购 → 部分进场 → 全部完成。

### R-14 锁单矩阵

| 单据 | 锁定条件 | 锁后行为 |
|---|---|---|
| 隐患 | 复查结论 = 合格闭环 | 编辑/删除禁用；对应预警转已读 |
| 质量缺陷 | 验收结论 = 合格 | 同上 |
| 现场签证 | 监理已确认 | 禁止编辑；且合同已完成时不允许新增签证 |
| 安全专项方案 | 已审批 | 禁止编辑 |
| 结算 | 已结清 | 禁止编辑 |
| 工资 | 已发放 | 禁止编辑 |

设备/班组「退场」不是锁单，而是**阻断下游**：退场设备不能记台班，退场班组不能加人/录考勤。

### R-15 编号

- 格式 `PREFIX-YYYYMMDD-0001`，按「前缀 + 日期」维度在**事务内**递增，并发 20 次不重号。
- 前缀可在设置页改，只影响新单。
- 手改编号保存时查重，**查重范围包含回收站**（避免恢复时撞号）。
- 备份导入另存时用 `-R1 / -R2` 后缀。

### R-17 时间边界

- 一律先 `dateOnly()` 归零再算**日历日差**，不用毫秒除法。
- 区间筛选右端 `setHours(23,59,59,999)`，**含首尾日**。
- 本周从**周一**开始；本月取自然月首尾（不是「到今天」）；季度/年度按自然区间。

### R-18 搜索

- 索引字段：单据类型名 + 编号 + 名称 + `searchFields` 描述文本 + 项目名 + WBS 编码/名称 + 附件文件名。
- 多词为 **AND**；排序权重 编号 3 / 名称 2 / 正文 1，同级按日期倒序。
- 摘要取命中词前后各 30 字并高亮。
- **单次返回上限 200 条**，首屏只渲染 50 条，剩余「加载更多」——5 万条数据下搜索 113ms（算法 41ms）。

## 3. 与计划的偏差（已在实现中固化，非缺陷）

| 编号 | 偏差 | 原因 |
|---|---|---|
| R-06 | 目录模式下读不到真实磁盘剩余（浏览器不提供），改用 origin 配额比例近似，且不拦大文件 | 能力限制；目录模式由用户自己管磁盘 |
| R-07 | `deletedAt` 未建索引，回收站查询是全表过滤 | 省写入成本；5 万条量级约 100ms，可接受（见 ADR-007） |
| R-18 | 搜索为内存全量扫描，未做持久化倒排索引 | 5 万条 41ms 够用；再上一个量级需引入索引表（见架构文档 §11） |
| R-04 | 父节点聚合只在展示层，不参与挣值 | 计划明确要求「挣值只认自身填报」 |
