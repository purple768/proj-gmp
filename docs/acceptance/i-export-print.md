# I. 导出与打印（AC-31 ~ AC-34）

## AC-31 打印抬头取设置值 🟡

| 项 | 内容 |
|---|---|
| 操作 | 设置页把打印抬头改成「XX项目部」→ 打印该单据 → 另存 PDF |
| 通过判定 | PDF 上表头已是修改后的文字；字段值与页面一致；A4 排版不乱 |
| 验证方式 | 半自动 |
| 证据 | `views/print/index.vue` 读取 `settingGet('printOrg')`；`smoke.mjs`「单据打印页渲染 A4 版式」确认打印路由可独立渲染完整单据（实测标题「隐患排查复查」）；样式使用 `@page { size: A4 }` + 打印专用布局 |
| 需目视 | 改抬头后打印预览里的表头文字与分页效果 |
| 手工步骤 | 设置页改抬头 → 保存 → 任一单据点「打印」→ 浏览器 Ctrl+P 预览 → 确认表头为「XX项目部」 |

## AC-32 甘特图导出 🟡

| 项 | 内容 |
|---|---|
| 操作 | 项目页甘特图点【导出图片】/【导出PDF】 |
| 通过判定 | 各生成 1 个能正常打开的文件，图形与页面一致 |
| 验证方式 | 半自动 |
| 证据 | `components/GanttChart.vue` 提供 PNG 导出（序列化 SVG → canvas → `toBlob` 下载），实测可生成文件；PDF 走浏览器「打印 → 另存为 PDF」，未内置 PDF 生成库 |
| 偏差说明 | 计划里 PDF 与图片都要「一键生成文件」。当前 PDF 依赖浏览器打印，产出等价但多一步；原因是引入 PDF 库会显著增大包体（约 300KB+），而浏览器打印对矢量图形更清晰 |
| 手工步骤 | 项目页 → 甘特图 → 导出 PNG 打开确认；Ctrl+P → 另存为 PDF |

## AC-33 台账导出勾选字段 🟡

| 项 | 内容 |
|---|---|
| 操作 | 台账导出：选项目 A、类型=隐患、起止=本月，勾选 5 个字段 → 导出 |
| 通过判定 | 表头恰为这 5 个字段；行数=该筛选下记录数；金额列千分位 |
| 验证方式 | 半自动 |
| 证据 | `views/export/index.vue`：字段模式新增「自定义勾选」，选单一单据类型后列出其全部字段（附件列除外），选几个就导出几列；`tests/m6.excel.test.ts` 验证表头与数据、多类型多 sheet、空结果集只有表头 |
| 需目视 | 勾选 5 个字段后打开 xlsx 核对该 5 列 |
| 手工步骤 | 导出中心 → 单据类型选「隐患排查复查」→ 字段模式选「自定义勾选」→ 只留 5 个 → 生成 Excel → 打开核对表头 |

## AC-34 含中文/特殊字符文件名的单据打印 ⚪

| 项 | 内容 |
|---|---|
| 操作 | 导出一个含中文名与特殊字符文件名的附件单据 PDF |
| 通过判定 | PDF 正常生成，无乱码、无报错 |
| 验证方式 | 手工 |
| 为什么不能自动 | 依赖系统字体与打印子系统，无头环境无法判定「无乱码」 |
| 已具备的支撑 | 附件落盘时文件名做 `[\\/:*?"<>|] → _` 过滤（`addAttachment`），中文原样保留（`attachment/YYYYMM/hash8_uid_原文件名`）；打印页只输出单据字段，附件仅列文件名 |
| 手工步骤 | 上传名为「施工方案（第3版）【最终】.pdf」→ 打开该单据 → 打印 → 另存 PDF → 确认文件名与内容均正常 |
