# F. 全局搜索（AC-20 ~ AC-24）

## AC-20 多词 AND ✅

| 项 | 内容 |
|---|---|
| 操作 | 搜索「3号楼 防水」（两个词） |
| 通过判定 | 只返回同时含两个词的记录；仅含一个词的不出现 |
| 验证方式 | 自动化 |
| 证据 | `tests/m5.search.test.ts`「多词为 AND 关系」；`perf.mjs`「多词为 AND 语义（跨记录两词不命中）」实测：单「配电箱」命中 200 条，「配电箱 防水卷材」命中 **0** 条（两词分属不同记录，AND 生效） |
| 实现 | `searchIndex()` 对每个词分别命中（编号 3 / 名称 2 / 正文 1），任一不命中即整条淘汰 |

## AC-21 高亮与摘要 ✅

| 项 | 内容 |
|---|---|
| 操作 | 查看结果第一条 |
| 通过判定 | 命中词黄色高亮；带类型标签；约 60 字上下文摘要 |
| 验证方式 | 自动化 |
| 证据 | `tests/m5.search.test.ts`「摘要截取命中词前后各 30 字并高亮」断言含 `<mark>`；`views/search` 渲染 `el-tag` 类型标签 + `highlight(snippet)` |
| 实测 | 结果条目形如：`[隐患排查复查] YH-20261106-0002 … 现场检查发现：3号楼 二层东侧 临边防护栏杆缺失` |

## AC-22 二次筛选与「当前 N 条」✅

| 项 | 内容 |
|---|---|
| 操作 | 结果页筛选 项目=A项目、类型=隐患+签证、时间=近 30 天 |
| 通过判定 | 结果条数正确收敛；页面显示「当前 N 条」与实际一致 |
| 验证方式 | 自动化 |
| 证据 | `tests/m5.search.test.ts`「按项目与类型二次筛选不重新检索」「日期区间过滤含首尾日」；搜索页渲染 `当前 {{ hits.length }} 条结果`（超过单页渲染量时追加「已显示前 50 条」） |
| 实现 | 二次筛选只对已建索引做内存过滤，不重读库；时间区间右端 `setHours(23,59,59,999)` 含首尾日 |

## AC-23 点击前询问是否跳转 ✅

| 项 | 内容 |
|---|---|
| 操作 | 点【查看详情】/条目「打开」 |
| 通过判定 | 先出现「是否跳转」选择；选「是」进入该记录；选「否」停留原页 |
| 验证方式 | 自动化 |
| 证据 | `flows.mjs`「搜索点开先询问是否跳转（AC-23）」实测弹窗文案 `查看详情 是否跳转到该记录详情？隐患排查复查 YH-20261106-0002 留在本页 跳转`；「选『留在本页』不跳转」断言 hash 仍为 `#/search?...` |
| 实现 | `open()` 使用 `ElMessageBox.confirm`，取消分支直接 return |

## AC-24 结果导 Excel 🟡

| 项 | 内容 |
|---|---|
| 操作 | 结果页点「导出结果」 |
| 通过判定 | 下载 xlsx 行数 = 当前筛选结果条数，含关键词所在文本列 |
| 验证方式 | 半自动 |
| 证据 | 导出实现 `exportHits()` 用 `hits.value`（当前结果集）生成单 sheet，列为 类型/编号/名称/项目/日期/摘要；`tests/m6.excel.test.ts`「生成的 xlsx 可被重新读取，表头与数据正确」保证写出的文件可回读、表头与行数正确 |
| 需目视 | 下载文件后打开核对行数与「摘要」列内容 |
| 手工步骤 | 搜索一个词 → 导出 → 打开 xlsx → 行数=「当前 N 条」 |
