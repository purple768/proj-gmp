# H. 回收站（AC-28 ~ AC-30）

## AC-28 删除进回收站与到期时间 ✅

| 项 | 内容 |
|---|---|
| 操作 | 删除 1 张签证单 |
| 通过判定 | 原列表消失；回收站出现该行，删除时间正确，到期清理时间 = 删除日 + 90 天 |
| 验证方式 | 自动化 |
| 证据 | `flows.mjs`「删除前弹出确认框」「删除后从列表移除（软删除）」「回收站可见被删单据」（按编号精确匹配）；`tests/m5.trash.test.ts`「软删记录出现在回收站，带到期时间 90 天」 |
| 实测 | 删除 QZ-20261106-0002 后列表 2→1 行，回收站出现该编号 1 条 |

## AC-29 从回收站恢复 ✅

| 项 | 内容 |
|---|---|
| 操作 | 回收站点【恢复】 |
| 通过判定 | 单据回到原模块列表，字段与附件完整；回收站该行消失 |
| 验证方式 | 自动化 |
| 证据 | `flows.mjs`「回收站恢复成功」（1→0 条）、「恢复后回到原模块列表且编号不变」（2 行，编号仍是 QZ-20261106-0002）；`tests/m5.trash.test.ts`「恢复后回到原列表且字段完整」「恢复时编号被占用则自动改号为 -R1」 |
| 实现 | 附件字节在软删期间保留（`state='pending-trash'`），恢复置回 `active`，因此附件不丢 |

## AC-30 永久删除 🟡

| 项 | 内容 |
|---|---|
| 操作 | 回收站点【永久删除】；先点「取消」，再确认一次 |
| 通过判定 | 弹出二次确认，文案含「永久删除后数据无法恢复」；点取消无变化；确认后记录与附件文件都被删除 |
| 验证方式 | 半自动 |
| 证据 | `tests/m5.trash.test.ts`「永久删除会释放附件；文件被多条单据引用时不误删」「90 天到期清理：只删到期记录，未到期保留」「剩余 ≤7 天的记录被标记为即将清理」 |
| 代码证据 | `views/trash/index.vue#purge()` 文案为「永久删除后数据无法恢复，是否继续？」；取消走 `ElMessageBox` reject，不会执行 `purgeDoc` |
| 需目视 | 点「取消」后列表与磁盘文件均无变化（可用资源管理器核对该附件文件仍在） |
