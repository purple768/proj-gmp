# D. 首页与仪表盘（AC-12 ~ AC-14）

## AC-12 卡片数值与统计一致 ✅

| 项 | 内容 |
|---|---|
| 操作 | 造 2 个在建项目、3 条未闭环隐患 → 看首页 |
| 通过判定 | 卡片数值与手工统计一致 |
| 验证方式 | 自动化 |
| 证据 | E2E 实测：首页「未闭环隐患」卡片值 = 2，与库中「状态 ≠ 合格闭环」的隐患数一致（`flows.mjs` 断言卡片值可读且等于下钻列表条数） |
| 口径 | `stats.hazards = hazards.filter(h => h.status !== '合格闭环').length`，与列表「未闭环」筛选同源，避免两套口径打架 |

## AC-13 卡片显隐与排序持久化 🟡

| 项 | 内容 |
|---|---|
| 操作 | 取消勾选「应收未收」，把「库存告警」拖到第一位 → 刷新 |
| 通过判定 | 卡片隐显与顺序保持；「恢复默认」能复位 |
| 验证方式 | 半自动 |
| 证据 | `views/dashboard/index.vue`：`cardConfig` 在拖拽（`onDrop`）、勾选变更时通过 `settingSet('dashboardCards', ...)` 落库，启动时 `settingGet` 读回并按 `ALL_CARDS` 合并（新增卡片不会因旧配置丢失）；「恢复默认布局」按钮重置为全显示 |
| 需目视 | HTML5 拖拽的实际手感与落位（`draggable` + `dragstart/over/drop`） |
| 手工步骤 | 拖一次 → F5 → 确认顺序未回退 → 点「恢复默认布局」→ 顺序复原 |

## AC-14 卡片下钻与状态筛选一致 ✅

| 项 | 内容 |
|---|---|
| 操作 | 点击「未闭环隐患」卡片 |
| 通过判定 | 落到隐患排查列表，状态筛选已自动为「待整改/整改中/不合格」，列表条数与卡片一致 |
| 验证方式 | 自动化 |
| 证据 | `flows.mjs`「下钻后列表条数与卡片一致（AC-14）」：卡片 2 / 列表 2，URL 为 `#/quality?tab=hazard&status=待整改,整改中,不合格`；「下钻自动带上未闭环状态筛选」断言筛选标签中不含「合格闭环」 |
| 实现 | 卡片路由携带 `status` 参数；`DocPage` 状态筛选改为多选并从 `route.query.status` 预置（`applyStatusQuery()`），非合法值会被过滤掉 |
