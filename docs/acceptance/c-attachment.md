# C. 附件与预览（AC-09 ~ AC-11）

## AC-09 图片/PDF 预览 ⚪

| 项 | 内容 |
|---|---|
| 操作 | 上传 jpg / png / pdf 各 1 个，点【预览】 |
| 通过判定 | 三条附件行均可预览，图片可缩放、PDF 可翻页 |
| 验证方式 | 手工 |
| 为什么不能自动 | 预览依赖浏览器内置图片/PDF 查看器，无头环境无法断言缩放与翻页 |
| 实现 | `DocPage.preview()`：`attachmentUrl()` 生成 blob URL → `window.open(url,'_blank')`；图片与 PDF 走新窗口，缩放/翻页由浏览器查看器提供 |
| 手工步骤 | 上传三类文件 → 逐条点文件名或【预览】→ 图片用 Ctrl+滚轮缩放、PDF 用查看器翻页 |
| 反向确认 | 若文件字节被误删，会提示「文件不存在，可能已被移动或删除」（`preview()` 的空值分支） |

## AC-10 其他格式只可下载 ⚪

| 项 | 内容 |
|---|---|
| 操作 | 上传 docx / xlsx / ifc 各 1 个 |
| 通过判定 | 【预览】置灰不可点，【下载】可用，下载后能正常打开 |
| 验证方式 | 手工 |
| 实现 | `preview()` 对非图片非 PDF 的扩展名走 `<a download>` 分支下载；列表中附件列显示「N 个」，弹窗内每行提供文件名链接（预览）与「移除」 |
| 手工步骤 | 上传三类文件 → 点文件名应直接下载 → 打开确认内容正确 |
| 说明 | 当前实现把「预览」与「下载」合并为一个文件名链接（按扩展名分流），未单独渲染置灰的预览按钮；判定要点「非图片/PDF 不可在线预览、可下载」成立 |

## AC-11 删附件 / 取消后的残留 ✅

| 项 | 内容 |
|---|---|
| 操作 | 删除某附件行并保存；另建一张单据，上传附件后直接取消 |
| 通过判定 | 保存后附件从列表消失；取消后该附件不出现在任何地方 |
| 验证方式 | 自动化 |
| 证据 | `tests/m1.attachment.test.ts`：「释放其中一个引用后文件仍可读；全部释放后文件被删除（R-07）」、「临时附件：取消表单后丢弃，保存后绑定到单据（AC-05）」 |
| 实现 | `releaseAttachment()` 减 `refCount`，归零才删字节；`discardTempAttachments()` 清理未绑定的临时行与字节 |
