# A. 基础与布局（AC-01 ~ AC-05）

## AC-01 菜单与面包屑 ✅

| 项 | 内容 |
|---|---|
| 操作 | 打开应用，依次点击左侧 12 项菜单 |
| 通过判定 | 12 项全部可见可点；点击任一项目，右侧内容区正确切换；面包屑随之一致 |
| 验证方式 | 自动化 |
| 证据 | `scripts/e2e/smoke.mjs`：`页面可打开 /#/xxx` 13 条 + `面包屑正确 /#/xxx` 3 条；`tests/m6.crumbs.test.ts` 7 例（含同级 tab 名冲突、未知 tab 不产生空级别） |
| 实测 | 侧边 12 个 `.menu-item`；面包屑 `首页仪表盘 / 质量安全 / 隐患排查复查`、`首页仪表盘 / 物资设备 / 库存汇总`、`首页仪表盘 / 进度管理` |

> 实现说明：面包屑为 `首页仪表盘 / 一级菜单 / 标签页`，前两级可点回跳，末级不可点（PRD §2.5）。本系统一层页面即一张单据列表，没有「子列表」这一级。

## AC-02 列表筛选与分页 🟡

| 项 | 内容 |
|---|---|
| 操作 | 打开任一单据列表，改筛选、翻页、改每页条数 |
| 通过判定 | 顶部筛选栏在；表头滚动不动；行悬停变色；底部「共 N 条」，切换条数后重新分页 |
| 验证方式 | 半自动 |
| 证据 | `perf.mjs`：翻页 439ms 后首行内容变化、关键词筛选 417ms、`.pager .muted` 显示「共 2555 条」；`DocPage.vue` 表格 `height="calc(100vh - 250px)"` + Element Plus 表头独立容器 |
| 需目视 | 行悬停底色（`.el-table` 默认 hover）、表头在滚动时是否视觉固定 |
| 结论 | 逻辑项通过；两项视觉项按上述步骤目视 |

## AC-03 新增弹窗形态 🟡

| 项 | 内容 |
|---|---|
| 操作 | 任一列表点「新增」 |
| 通过判定 | 弹窗宽度符合约定；底部左「关闭」右「保存」；必填项带红星 |
| 验证方式 | 半自动 |
| 证据 | `smoke.mjs`「新增隐患弹窗可打开并填写」读取 14 个 form-item 且必填项可填；`DocPage.vue` 底部按钮顺序为 关闭 → 保存，必填项 label 由 `required` 生成 `*` |
| 需目视 | 弹窗宽度（按字段 `span` 栅格自适应，默认 900px） |
| 结论 | 结构项通过；宽度按上述目视 |

## AC-04 必填留空不入库 ✅

| 项 | 内容 |
|---|---|
| 操作 | 新增单据，必填项留空，点保存 |
| 通过判定 | 报错提示出现、字段标红、数据未入库 |
| 验证方式 | 自动化 |
| 证据 | `tests/m1.validate.test.ts`「必填字段为空时逐项报错，不短路」；E2E 实测：隐患单留空「限期整改日期」→ 提示「限期整改日期不能为空」，弹窗不关闭，列表行数保持 2 行不变 |
| 结论 | 通过（错误一次性全列，不逐条挤牙膏） |

## AC-05 关闭弹窗丢弃内容与临时附件 ✅

| 项 | 内容 |
|---|---|
| 操作 | 新增单据，填内容并上传附件，直接「关闭」 |
| 通过判定 | 已填内容与本次临时上传的附件全部丢弃，列表无变化 |
| 验证方式 | 自动化 |
| 证据 | `tests/m1.attachment.test.ts`「临时附件：取消表单后丢弃，保存后绑定到单据（AC-05）」 |
| 实现 | 新建时附件 `state='temp'` 挂在临时 id 上；关闭时 `discardTempAttachments()`；保存时 `bindTempAttachments()` 迁移到真实单据 id |
