# 工程管理本地版（GMP）

单机、离线、数据不出本机的工程项目管理系统。Vue 3 + Element Plus + IndexedDB，无后端、无需安装数据库，静态托管即可运行。

覆盖 32 类工程单据：进度填报、合同/变更/签证/报审/结算、预算与成本、质量与安全、物资与设备、图纸与归档、劳务与工资。

## 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:3100
```

首次打开会自动写入一套演示数据（1 个项目 + 8 个 WBS + 各模块若干单据），可直接点开看效果。

打包给同事用：

```bash
npm run build      # 产物在 dist/
```

`dist/` 需通过 HTTP 服务打开（双击 index.html 不行，浏览器会拦模块加载与 IndexedDB）。本机可用 `npx serve dist`。

## 常用命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 开发服务器（端口 3100） |
| `npm run build` | 生产构建 |
| `npm test` | 单元/集成测试（Vitest + fake-indexeddb，Node 环境） |
| `npm run e2e` | 浏览器冒烟（Puppeteer + 本机 Edge） |
| `node scripts/e2e/flows.mjs` | 浏览器业务流程（新建→删除→回收站→恢复→导出→备份） |
| `node scripts/e2e/perf.mjs` | 性能验收（5 万条搜索/翻页/筛选） |
| `node scripts/e2e/perf.mjs --soak` | 追加 50 轮增删改（约 5 分钟） |
| `node scripts/seed-50k.mjs --count 50000` | 往当前浏览器库写入 5 万条压测数据；`--clean` 清理 |

> E2E 依赖本机已安装 Edge/Chrome（脚本会自动找常见安装路径），且需先 `npm run dev`。

## 目录结构

```
src/
├─ shared/          纯函数：金额（分运算）、日期（日历日差）、id/hash
├─ core/
│  ├─ db/           Dexie schema（41 张表）+ 仓储（列表/增删改/软删/设置）
│  ├─ engine/       单据引擎：字段类型、校验、计算字段、数值规整
│  ├─ docs/         33 份单据配置（1 骨架 + 32 业务单据）+ 面包屑
│  └─ services/     业务服务：编号/附件/WBS/甘特/结算/成本/库存/挣值/预警/
│                   搜索/回收站/今日计划/备份/质量联动/钩子/Excel/导入
├─ components/      DocPage（通用单据页）、DocTabs、GanttChart
├─ views/           13 个页面（12 菜单 + 全局搜索）+ 打印页
└─ layout/          侧边菜单、项目切换、全局搜索、预警徽标、授权横幅
tests/              20 个测试文件 / 151 个用例
scripts/
├─ lib/             E2E 交互工具、5 万条数据工厂
├─ e2e/             smoke / flows / perf
└─ seed-50k.mjs     数据工厂 CLI
docs/               架构、规则、手册、ADR、42 条验收记录
```

## 数据存在哪

| 内容 | 位置 |
|---|---|
| 台账数据（项目/单据/设置） | 浏览器 IndexedDB（库名 `GMP_DB`） |
| 附件字节 | 优先「你选择的本地文件夹」→ 其次 OPFS → 最后 IndexedDB |

**数据绑在这台电脑的这个浏览器上。** 换机、重装、清浏览器数据前，务必在「系统设置 → 备份」里导出整包备份（含附件）。

## 已知限制（都是取舍，不是缺陷）

1. **导入不是原子操作**：按表逐写，中途关页面可能留下部分数据。导入前先导出一份当前数据（ADR-004）。
2. **搜索是内存全量扫描**：5 万条 50~170ms 够用；再上一个量级需要持久化倒排索引。
3. **打印走浏览器 `window.print()`**：A4 版式一致，PDF 用「另存为 PDF」，不内置 PDF 库。
4. **甘特图 PDF 依赖浏览器打印**，PNG 为一键导出。
5. **目录授权需偶尔重新确认**：浏览器重启后可能失权，顶部横幅提供「重新授权」，数据不会丢。
6. **单机单用户**：无并发锁，冲突只可能发生在导入备份时。
